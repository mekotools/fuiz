# MekoTools: Fuiz

Oeffentliches Spiegel-Abbild fuer **Fuiz** (Live-Quiz, https://fuiz.org).

Die Abbilder werden aus der amtlichen Quelle (registry.gitlab.com/fuiz) digest-genagelt
nach ghcr.io/mekotools gespiegelt. Der Push geschieht aus diesem oeffentlichen Repo,
damit die Pakete ohne Anmeldung ziehbar sind.

| Paket | Quelle |
|---|---|
| ghcr.io/mekotools/fuiz-website | registry.gitlab.com/fuiz/website |
| ghcr.io/mekotools/fuiz-server | registry.gitlab.com/fuiz/game-backend/fuiz-server |
| ghcr.io/mekotools/fuiz-corkboard | registry.gitlab.com/fuiz/game-backend/corkboard-server |
